# Bundled third-party marks

The apps load no third-party assets at runtime (ADR 0010), so attribution logos ship here.

| File            | Source                                                                    | Rules                                                                                                                                                                                                                     |
| --------------- | ------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `tmdb-logo.svg` | TMDB "blue short" logo, unchanged, from the TMDB logos & attribution page | Only to credit TMDB as a data source; less prominent than the product's own branding; never modified, recoloured or rotated; always shown with "This product uses the TMDB API but is not endorsed or certified by TMDB." |

MusicBrainz and the Cover Art Archive are credited by name only; no logo is bundled.
