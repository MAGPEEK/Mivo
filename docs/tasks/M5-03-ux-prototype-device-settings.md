# M5-03 Prototype: settings for this device and shortcut help
Owner: mivo-ux
Depends on: none
Files/areas: `docs/design/prototypes/settings.html`, `docs/design/prototypes/README.md`

## Goal
Prototype for `/settings/app` (AD-01, AD-03, ux-spec 11.2) and the keyboard help sheet (PL-09),
so the device preferences all M5 features rely on have one agreed home.

## Acceptance criteria
- [ ] Sections: Appearance (language, hero on/off, theme if any), Library layout (reset sidebar
      layout SH-14, default view style, card size), Playback (auto play, default speed, subtitle
      size placeholder marked M4, quality placeholders marked M4), Search (clear recent
      searches), About (server version).
- [ ] Every control states its storage (per device, local storage) and its milestone.
- [ ] Keyboard help sheet lists all keys of PL-09 and Ctrl+K; opens with "?".
- [ ] Legend, open questions with defaults, README row `draft`; self-contained; en/de.
- [ ] Gates: none (docs only); owner approval before M5-63 and M5-80.

## Notes
Settings for admins (server) are out of scope here; this page is available to every user.
