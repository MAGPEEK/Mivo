Legend – prototype "Playback options panel" (draft, M4-16b)
  • ux-spec ids: PL-10 (quality: Original / Automatic / ladder steps below the source, ADR 0030 §6), PL-11 (audio tracks, restart with spinner), PL-12 (subtitles: Off, text tracks, forced/SDH/external badges, image track with burn-in hint), PL-13 (subtitle size only), PL-40 (mode badge changes live), PL-41/PL-42 (stream-info overlay with reasons, warnings and hints). PL-04 (bar) and PL-14/PL-15 (auto play, speed) are shown as approved in detail.html. Target milestone: M4.
  • Not shown: "Search online…" (PL-20, M6), "Upload…" (PL-21, M7), position/background of PL-13 ("More"), styled ASS (M4-19, post-0.1.0), TV side panel.
  • How to try it: the gear button in the player bar opens the panel (focus lands on the current audio track; Esc, ✕ or a click on the video closes it and focus returns to the gear). In a list ↑/↓ move, Enter/Space choose, Tab goes to the next section. I or the mode badge opens the stream info. The bar "Simulate" switches the sample file and the server state.
  • States: Several tracks (MKV, 5 audio, 5 subtitles – default state is Transcode because of E-AC3; pick an AAC track to see Direct Stream), One audio track (MP4, Direct Play, ladder shows only steps below the source), No subtitles (also an audio track without a language tag). Server cannot burn in + the PGS track = switch refused (subtitle_burn_in_unavailable). Slow switch keeps the loading state for 4 s.
  • Responsive: Preview 1440 / 1024 / 390. Phone: bottom sheet with one section per tab.
  • Sample data is invented and follows the 1.16.0 contract (MediaStream, SubtitleTrack, PlaybackSession, StreamDecision, PlaybackReason). The server decision is simulated in the page. Resolutions per ladder step (20/12/8 → 1080p, 4 → 720p, 2/1 → 480p) are an assumption from ADR 0030 §6.
  • Open questions for the owner (default in brackets – used if you do not object):
    1. Q1 – Section order: as in the ux-spec (Quality, Audio, Subtitles, Size); keyboard focus and the phone sheet start on Audio because language switching is the main use. Or move Audio to the first column? [as drawn]
    2. Q2 – The panel stays open after a choice so the new mode is visible; Esc, ✕ or a click on the video closes it. Or close it after every choice? [stays open]
    3. Q3 – Rows say beforehand what a choice costs ("converted to AAC", "burned in – video is converted"). [yes]
    4. Q4 – Burn-in refused: subtitles are Off afterwards (ADR 0030 §3), with a message and a note on the row. Alternative: fall back to the text subtitle that was shown before. [Off]
    5. Q5 – "Original" stays checked as long as no bitrate limit is chosen, even when only the audio is converted (ux-spec PL-10 says: checked for Direct Play/Direct Stream only). The mode line below explains the difference. [as drawn]
    6. Q6 – Fixed steps sit behind "Show all steps" (ux-spec); a chosen step stays visible. Or always list them? [behind "Show all steps"]
    7. Q7 – Phone: tabs inside the bottom sheet, or a drill-down list (Audio › list › back)? [tabs]
    8. Q8 – Audio rows lead with the language name, codec/channels/title below, tracks in file order. Or group by language? [as drawn]
    9. Q9 – ASS subtitles are shown as plain text with the note "without styling" until M4-19. [yes]
